## 🚀 Featured projects

All four were built through AI-assisted development with Claude Code, with me leading the concept, requirements, testing, debugging and deployment.

### 🍌 [BananaMaps](https://github.com/azizalharbi17/BananaMaps): blockchain analytics and wallet risk scoring
**[Live: bananamaps.io](https://www.bananamaps.io)**

Turns a token's top 150 holders into an interactive bubble map. It finds clusters of related wallets, labels exchange and contract wallets, and gives each token a 0–100 holder-concentration risk score.

- Covers Ethereum, BNB Chain, Base, Solana and Robinhood Chain.
- A background indexer keeps maps fresh within daily API budgets.
- Includes a public REST API with Stripe billing and an embeddable map for other sites.

`Next.js` `TypeScript` `Supabase` `Stripe` `d3-force` `Node.js worker`

### 🔄 [BananaFlip](https://github.com/azizalharbi17/BananaFlip): crypto comparison and investment calculators
**[Live: bananaflip.io](https://www.bananaflip.io)**

"Can it flip?" Pick two coins to see Coin A's price at Coin B's market cap.

- Includes ROI, DCA-vs-lump-sum and "Moon Math" calculators built on real daily price history.
- Every comparison gets a shareable page.
- Trending memecoins are discovered automatically every day.

`Next.js` `TypeScript` `Supabase` `Vercel Cron` `GitHub Actions`

### 📊 [BananaScreener](https://github.com/azizalharbi17/BananaScreener): multi-chain crypto market screener
**[Live: bananascreener.io](https://www.bananascreener.io)**

A screener for trending DEX trading pools across 13 blockchains, expanded from an open-source starting point. Token pages show live charts, trades, top traders and holder clusters, with holder data from BananaMaps. A database-first cache keeps the site within upstream API rate limits.

`Next.js` `JavaScript` `Supabase` `GeckoTerminal API` `Lightweight Charts`

### 📈 [F-Score Stock Screener](https://github.com/azizalharbi17/F-Score-Stock-Screener): fundamental stock analysis
Screens about 330 US mid- and large-cap stocks for companies that are cheap compared with their sector and financially healthy, using the 9-point Piotroski F-Score.

- Ties every score to the company's SEC filings.
- Charts how the price moved after each filing.
- Suggests covered-call setups in plain language.

`Python` `Streamlit` `pandas` `Plotly` `SEC EDGAR API` `yfinance`
